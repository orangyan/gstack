# GStack 项目分析文档索引

## 📚 文档概览

本目录包含 GStack 项目的完整分析文档，从产品、技术、代码和功能四个核心维度深入剖析了这个革命性的 AI 软件工厂。

## 📑 文档列表

### 01 - 产品概述
**文件**：[01-产品概述.md](./01-产品概述.md)

**内容概要**：
- 产品定位与核心价值主张
- 23+ 专家角色技能矩阵
- 完整的开发流程（思考→计划→构建→审查→测试→发布→反思）
- 浏览器自动化核心优势
- 生产力数据（810x 压缩比）
- 技术哲学三大原则（Boil the Lake、Search Before Building、User Sovereignty）
- 安装部署与商业模式
- 生态系统集成（GBrain、语音输入、OpenClaw）
- 与竞品对比

**适合读者**：产品经理、创始人、首次了解 GStack 的用户

**关键洞察**：
> "这不是 Copilot，是团队" - 23 个专家角色覆盖完整 SDLC

### 02 - 技术架构
**文件**：[02-技术架构.md](./02-技术架构.md)

**内容概要**：
- 整体架构设计（CLI → HTTP → 服务器 → CDP → Chromium）
- 技术栈选择（为什么选择 Bun、Playwright vs Puppeteer）
- 守护进程模型（亚秒级命令、持久化状态）
- 安全模型（双监听器隧道架构、令牌体系、提示注入防御）
- 命令系统（100+ 命令、不受信任的内容包装）
- 浏览器集成（Cookie 导入、GStack Browser、Handoff 机制）
- 扩展架构（侧边栏、WebSocket 认证）
- 技能系统（模板生成流程、令牌上限、主机配置）
- 测试架构（三层测试、基于 diff 的选择、双层系统）
- 性能优化与部署

**适合读者**：架构师、后端工程师、DevOps 工程师

**关键洞察**：
> "守护进程模型：首次 3s，后续 ~100-200ms" - 性能是核心

---

### 03 - 代码结构
**文件**：[03-代码结构.md](./03-代码结构.md)

**内容概要**：
- 项目目录树（完整的 90+ 目录结构）
- 核心模块详解
  - Browse（浏览器自动化）- CLI、服务器、命令注册表、快照系统、安全层
  - Design（GPT Image API）- 生成、变体、品味学习
  - Hosts（主机配置系统）- 多 AI 代理支持
  - Scripts（构建 + DX 工具）- 技能文档生成器、解析器
  - Test（测试基础设施）- 技能解析器、会话运行器、LLM-judge
- 数据流（浏览器命令流、技能调用流、文档生成流、E2E 测试流）
- 配置与状态（全局配置、项目配置、浏览器状态、会话状态）
- 扩展点（添加新命令、新技能、新主机、新解析器）

**适合读者**：前端工程师、全栈工程师、贡献者

**关键洞察**：
> "单一真相来源" - `commands.ts` 用于命令，`hosts/index.ts` 用于主机，`.tmpl` 文件用于技能

### 04 - 功能结构
**文件**：[04-功能结构.md](./04-功能结构.md)

**内容概要**：
- 功能分层架构（战略→架构→实现→审查→测试→发布→反思）
- 核心功能矩阵
  - 按角色分类（23+ 专家角色）
  - 按阶段分类（7 个 SDLC 阶段）
- 详细流程示例（黑暗模式实现的端到端流程）
- 功能交互图（数据流图、依赖关系图）
- 高级功能
  - 并行工作流程（Conductor 集成）
  - 跨模型协作（`/codex` 三种模式）
  - 浏览器技能生态系统（域技能、CDP 逃生舱口）
  - 设计工作流程（Shotgun → HTML 管道）
  - 安全层（6 层提示注入防御）
  - 持续检查点模式
- 功能对比矩阵（vs 传统工具、vs 其他 AI 编程工具）

**适合读者**：产品经理、技术负责人、高级工程师

**关键洞察**：
> "完整的 SDLC + 流程优先 + AI 原生" - 为 AI 协作从头设计的工作流程
