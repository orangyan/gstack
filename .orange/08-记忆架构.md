# 08 记忆架构

## gstack 的记忆形态

gstack 没有 MEMORY.md 或 SOUL.md 文件，而是采用**动态 JSONL 数据库**，由 bash 工具读写，Claude 通过自然语言摘要感知。

---

## 8.1 三层记忆结构

| 层级 | 存储路径 | 格式 | 范围 | 生命周期 |
|------|---------|------|------|---------|
| **运营学习** (operational) | `~/.gstack/projects/{slug}/learnings.jsonl` | JSONL: {skill, type, key, insight, confidence, source, branch, commit, files[]} | 项目级或跨项目 | 持久，手动管理 |
| **会话状态** | `~/.gstack/sessions/$PPID` | touch 文件 (存在=活跃) | 本地进程 | 120 分钟后自动清理 |
| **分析遥测** | `~/.gstack/analytics/skill-usage.jsonl` | JSONL: {skill, ts, repo} | 本机全局 | 持久，按月轮转 |

---

## 8.2 学习存储机制

**写入 (技能完成时):**
```bash
gstack-learnings-log '{
  "skill": "qa",
  "type": "browser-quirk",
  "key": "safari-localstorage",
  "insight": "Safari localStorage.setItem is async; always await",
  "confidence": 0.9,
  "files": ["src/providers/ThemeProvider.tsx"]
}'
```

**读取 (技能启动时):**
```bash
gstack-learnings-search --limit 10 --skill qa
```

**去重:** 相同 key+type → 读时取最新版本

**跨项目:** `gstack-config get cross_project_learnings` 控制，首次询问用户

**管理界面:** `/learn` 技能提供 review/search/prune/export 界面

---

## 8.3 与其他项目的记忆形态对比

| 维度 | gstack | deer-flow | hermes-agent | nanobot |
|------|--------|-----------|--------------|---------|
| **记忆格式** | JSONL 数据库 | MEMORY.md (结构化 Markdown) | Facts JSON (SQLite) | Dream 两阶段 (JSON) |
| **写入方式** | bash 工具调用 | LLM 提取后 patch | LLM 提取后 INSERT | Consolidator 异步 |
| **读取方式** | bash 搜索命令 | 注入系统提示 | FTS5 向量检索 | 加载到上下文 |
| **范围** | 项目级 + 跨项目 | 用户级 | 全局 | 会话级 |
| **类型** | 操作性知识 (技巧/陷阱) | 事实性知识 (偏好/习惯) | 事实 + 历史 | 事实 + 概念 |
| **过期机制** | 手动 prune | 无 | 无 | Dream 周期整合 |
| **搜索能力** | 关键词匹配 | 无 | FTS5 全文搜索 | 无 |
| **跨进程访问** | ✅ (文件系统) | ✅ (文件系统) | ✅ (SQLite) | ❌ (内存) |

## 8.4 gstack 的特色：Preamble 记忆注入

每次技能启动时，Preamble bash 代码块自动将学习注入上下文：

```bash
# Preamble 中的学习搜索（每次技能启动）
_LEARNINGS=$(gstack-learnings-search --limit 10 2>/dev/null || echo "")
if [ -n "$_LEARNINGS" ]; then
  echo "## Project Learnings (auto-recalled)"
  echo "$_LEARNINGS"
fi
```

这与 MEMORY.md 的静态注入不同——每次都是动态搜索最相关的学习。

---

## 8.5 SKILL.md 本身作为程序性记忆

gstack 最独特的"记忆"形式是 SKILL.md：

- **不是运行时数据**，而是 Claude 的**程序性指令**
- 由 `.tmpl` 生成，注入了 preamble、resolver、host 特定逻辑
- 从 `~/.gstack/learnings.jsonl` 提炼的最佳实践被集成进 `.tmpl` 文件
- 相当于将"过去学到的知识"编码进了技能本身

这种"学习 → 更新模板 → 重新生成 SKILL.md"的循环，是 gstack 独有的**元学习机制**。
